Interactive Walkthrough (.html)

Export a self-contained interactive "Guide Me" simulation where learners click the highlighted target area to proceed with sound effects, hint animations, and confetti.

📄

Microsoft Word (.docx)

Export a formatted Word document with custom step headers, descriptions, callout note boxes, expected results, and embedded high-res screenshots.

📊

PowerPoint Presentation (.pptx)

Export a widescreen 16:9 slide deck with custom cover slide, individual step slides, and full-resolution embedded screenshots.

💾

JSON Portable Backup

Export a complete, self-contained JSON backup of the workflow with embedded base64 screenshots that can be restored on any machine.

📁

Self-Contained HTML

Creates a single, highly readable SOP guide with all screenshots embedded as offline base64. Ideal for printing to PDF or sharing over email.

📝

Markdown Document

Export as clean Github Flavored Markdown. Perfect for copying directly into Confluence, Notion, Github, or your internal knowledge base.

⚡

📊

Structured CSV

Export all actions, timings, values, selectors, and descriptions into a spreadsheet table format for audits or CSV logs.
