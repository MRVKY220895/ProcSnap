# Awesome Design Systems (DESIGN.md Library)

A comprehensive library of **74 production design systems** reverse-engineered and specified with exact color palettes, typography scales, spacing rules, card elevation, border radiuses, and component interaction tokens.

## How to Use This Skill

1. When a user requests a specific aesthetic (e.g. *"Design this page in the style of Linear / Stripe / Apple / Raycast / Supabase"*):
   - Locate the corresponding system in `.agents/design-systems/design-md/<system-name>/DESIGN.md`.
   - Read the exact design tokens: `colors`, `typography`, `surfaces`, `hairline`, `shadows`, and `components`.
2. Apply the exact CSS custom properties, Tailwind tokens, or inline styles directly in the code.
3. If the user does not specify a system, select the best fitting one from the catalog below:
   - **Technical B2B / SaaS**: `linear.app`, `supabase`, `raycast`, `vercel`, `posthog`, `resend`, `warp`
   - **Luxury / Minimalist Consumer**: `apple`, `claude`, `notion`, `figma`, `superhuman`, `framer`
   - **Fintech / High-Trust Enterprise**: `stripe`, `revolut`, `wise`, `coinbase`, `mastercard`
   - **Automotive / Precision Engineering**: `bmw-m`, `porsche`, `ferrari`, `tesla`, `bugatti`, `spacex`
   - **Editorial / Media**: `theverge`, `wired`, `mintlify`

```css
  --ink: #f7f8f8;
  --ink-muted: #d0d6e0;
  --ink-subtle: #8a8f98;
  --hairline: #23252a;
  --hairline-strong: #34343a;
}
```
