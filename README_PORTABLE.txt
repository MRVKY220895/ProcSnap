HOW TO USE PROCSNAP (NO ADMIN PRIVILEGES REQUIRED):
------------------------------------------------------------------------

OPTION A: ONE-CLICK INSTALLER (Recommended)
   - Double-click "install.bat"
   - Installs to %LOCALAPPDATA%\ProcSnap (100% user-space)
   - Automatically adds Desktop & Start Menu shortcuts
   - Guides you to install the extension in your favorite browser

OPTION B: RUN PORTABLE (No Installation)
   - Double-click "start.bat"
   - The Studio opens at http://127.0.0.1:8000/dashboard/dashboard.html

BROWSER EXTENSION SETUP:
   - Run "install_extension.bat" anytime to pick your favorite browser
     (Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi).
